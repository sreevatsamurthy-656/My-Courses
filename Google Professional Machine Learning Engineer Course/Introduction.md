# Course Introduction

So basically in this entire course, you will learn:

1. Explore AI Foundations
2. Explore AI on the Google Cloud
3. Discover the infrastructure of AI
4. Get Hands-on with powerful tools like BigQueryML
5. Then go into Generative AI (GenAI) on Google CLoud where the AI learns to create brand-new content
6. The course goes into foundational models like:
 - Gemini
 - Veo (for Videos)
 - Imagen (for Images)
7. We will also learn about:
 - Prompt Engineering
 - Multi-modality
8. We will also learn about AI Agents - Fully autonomous assistant that generates content and takes actions for you.
9. We will learn about various AI development options like:
 - Gemini Enterprises and AutoML for No-Code solutions
 - Pre-trained APIs for Low-Code options
 - BigQueryML and custom training with Vertex AI for Code-Based approaches
10.This course discusses the entire AI Development Workflow from:
 - Data Preparation
 - Model Development
 - Model Serving
